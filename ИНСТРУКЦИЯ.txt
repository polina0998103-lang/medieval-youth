ПРИЛОЖЕНИЕ «ЮНОСТЬ ЗА КРЕПОСТНЫМИ СТЕНАМИ»

Это PWA — сайт, который можно добавить на экран iPhone как приложение.
Это не отдельный файл IPA и не публикация в App Store.

ВАЖНО:
Чтобы iPhone предложил «На экран Домой» как веб-приложение, сайт должен
быть размещён в интернете по HTTPS. Не открывайте index.html как локальный файл.

ФАЙЛЫ:
- index.html — страницы приложения
- manifest.webmanifest — имя, цвет и параметры приложения
- service-worker.js — кэширование для базовой работы офлайн
- icons/ — иконки приложения

После размещения:
1. Откройте адрес сайта в Safari на iPhone.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Если есть переключатель «Открывать как веб-приложение» / «Open as Web App»,
   включите его.
5. Нажмите «Добавить».

Первое открытие и установка требуют интернета. После первой загрузки
часть приложения может открываться без сети; внешние ресурсы не используются.
